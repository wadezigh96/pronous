# PRONOUS Product Map

## One-line utility

**PRONOUS makes tokenized-stock price gaps understandable and actionable without hiding the guardrails.**

## Core loop

**Watch → Compare → Explain → Guard → Prepare → Confirm**

## Primary user questions

1. What tokenized stocks are available?
2. What is the token price?
3. What is the reference price?
4. Is the reference market open or closed?
5. How large is the gap?
6. Why does the gap exist?
7. Is an action allowed by policy?
8. What would the transaction look like?
9. Has it been simulated?
10. What requires my confirmation?
