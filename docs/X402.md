# PRONOUS x402 / B402 Seller

## Purpose

PRONOUS can expose **paid market intelligence** to AI agents without turning payment into trading authorization.

```
Agent
  ↓
HTTP 402
  ↓
B402 / x402 payment
  ↓
PRONOUS live market intelligence
  ↓
result
```

Payment buys access to intelligence only. It does **not** authorize a swap, wallet signature, or transaction broadcast.

## Separation from trading

The paid seller path is deliberately read-only:

```
x402 payment
    ↓
market intelligence
    ↓
optional quote
    ↓
simulation
    ↓
explicit user confirmation
    ↓
wallet signing
    ↓
BSC transaction
```

An x402 payment never skips the execution gates.

## Seller project

The BNB Agent Studio seller was generated separately from the main PRONOUS repository so that seller runtime files and local wallet storage do not contaminate the PRONOUS application.

Local project:

```
~/pronous-x402-seller/PronousX402
```

No wallet password, private key, keystore contents, or merchant credentials belong in this repository.
